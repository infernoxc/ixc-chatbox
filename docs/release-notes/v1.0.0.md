## IXC ChatBox v1.0.0: first public release

**Twitch, Kick and YouTube chat in one OBS dock**, with replies, neural text-to-speech, an on-stream overlay and an optional phone
view. It uses [Streamer.bot](https://streamer.bot) (free) for the platform connections.

### Features
- One list for all three platforms, with a platform tag and colour on every message, plus emotes, badges and avatars (Kick and YouTube)
- Dock mode (auto-follow, "new messages" button, viewer counts) and overlay mode (transparent, messages fade out)
- **Reply box:** send to All / Twitch / Kick / YouTube, with `!command` and `@user` suggestions and click-to-reply
- **Neural TTS:** 5 voices that viewers hear through an OBS source; skips commands, links, bots and your own bot replies
- **Phone view** (off by default): private networks only, random key, QR code in the dock
- Per-user installer (no admin), start at login, Start menu shortcuts, clean uninstaller

**Setup:** [docs/INSTALL.md](https://github.com/infernoxc/ixc-chatbox/blob/main/docs/INSTALL.md). In short: turn on Streamer.bot's WebSocket
server, then add the dock `http://localhost:8767/chat/chat.html?dock=1&viewers=1&own=YOURNAME` and the TTS source
`http://localhost:8767/chat/tts.html` in OBS.

### Supported versions
Windows 10/11, OBS Studio 30+, Streamer.bot 1.0+. **Tested on Windows 11 (build 26200), OBS Studio 32.2.2, Streamer.bot 1.0.7.**

### Known issues
- Sending requires Streamer.bot WebSocket authentication to be **enabled**; reading chat needs it **not enforced**.
- YouTube replies only work while you're live.
- Twitch chat events don't include profile pictures, so Twitch users show their initial.
- The neural TTS voices use Microsoft Edge's public but unofficial endpoint. If it's unavailable, the dock falls back to a local Windows voice.
- The files aren't code-signed, so SmartScreen may warn you. Choose *More info › Run anyway* for files from this page only.
