**IXC 3.0.2** fixes chat that dropped out and messages that were never read aloud during long streams.

### Fixed
- **Kick chat** no longer drops and reconnects every ~150 seconds when chat is quiet (IXC now sends the keepalive Kick expects).
- **YouTube chat** no longer flips to "Not live" after a short hiccup: IXC checks again before it says so, and the chip now tells you why (for example "scheduled but not started - press Go live in YouTube Studio").
- **YouTube messages sent while IXC was reconnecting** (same stream, gap up to 5 minutes) are now read out and shown as new instead of being treated as old history.
- **Chat voice limits** can no longer be set low enough to silently drop most messages. New defaults read more of a busy multi-platform chat: 15 waiting, skip after 90 s, 40 per minute, same person waits 2 s.

### Upgrading
Run `IXC-Setup-v3.0.2.exe`. Settings, queue and accounts are kept and backed up first (rollback is automatic if the update fails).

### Tested
Automated on every push: IXC runs against fake Twitch, Kick, YouTube, Rumble, OBS, Streamer.bot and GitHub servers (Linux), and the Windows build, install, update and uninstall are run on a clean machine.
