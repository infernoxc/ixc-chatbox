# IXC 3.3.0-rc.1 (release candidate)

A release candidate: built from the tested code, **not** a finished product. Read "Known limitations" before relying on it.

## Install (Windows 10/11, OBS Studio 28 or newer)
1. Close OBS. Unzip `IXC-Suite-v3.3.0-rc.1.zip`, double-click **Install.bat**. (If you have the setup program `IXC-Setup-v3.3.0-rc.1.exe` use that instead; it does the same.)
2. It installs for your Windows user only (no administrator rights) into `%LOCALAPPDATA%\IXC-OBS`, starts IXC with Windows (only a tray icon until OBS opens), turns on OBS's WebSocket server and adds the IXC panels to OBS.
3. Open OBS. IXC opens by itself; click the tray icon or open the **IXC** dock to see the dashboard.
4. Upgrading from 3.x keeps your settings and keys (a backup is made first in `%LOCALAPPDATA%\IXC-OBS\backups`).

## First-run setup (about 5 minutes)
1. **Platforms & Accounts**: type your Twitch / Kick / YouTube channel name. Reading chat needs nothing else.
2. To **reply**, moderate or get follower alerts you need your own free developer app per platform (Platforms & Accounts > Your apps shows the exact steps and the redirect addresses). Without it IXC says precisely which step is missing.
3. **Music / Chat voice**: IXC adds its sources to OBS by itself (scene "IXC Audio"). If they ever show "isn't running in OBS", press **Set up OBS again** (Overview).
4. **Multistream Studio** is optional and experimental (see below).

## What is new since 3.2.0
- YouTube: a channel name of exactly 11 characters was read as a video id (live stream never found) - fixed. "Not live" is now shown only when YouTube's page was read and shows no stream; a blocked, unreadable or wrong-name page is an error with the reason. A refused Google sign-in explains the "app in Testing" 7-day limit.
- Replies: when IXC cannot reply, it names the exact missing step per platform (add your app / connect / sign-in expired).
- Music, chat voice and overlays reload by themselves when OBS opened before IXC answered (they used to stay broken until repaired by hand).
- Multistream Studio (new): destinations with encrypted stream keys, a server check, and a native relay that forwards **OBS's single encoded stream** to up to 8 RTMP/RTMPS servers. Off until you start it.
- Dashboard: new navigation (Overview, Chat, Platforms & Accounts, Multistream Studio, Vertical Studio, Automation Studio, OBS Control, Settings, ...). Vertical Studio and Automation Studio are honest status pages (see limitations).
- OBS Control shows a read-only report of what your OBS can do (version, outputs, canvases, plugins).
- Diagnostics export test now runs on Windows (no keys/tokens/IPs/user name in the export).

## Known limitations (read these)
- **Multistream relay**: tested only against local fake servers. It was never run against a real platform or a real OBS stream. Every destination gets exactly the same video/audio OBS encodes: **no per-destination bitrate, encoder, resolution or codec**. To use it, OBS's stream service must be set to *Custom* with the server and key shown in Multistream Studio (IXC does not change OBS for you). Platform ingest rules (Kick/TikTok per-account addresses, short-lived Facebook keys, accounts that need LIVE access) are not verified. Try with a private/unlisted stream first.
- **Vertical Studio** only reports what OBS and the Aitum Vertical Canvas plugin say. It cannot create, edit or start a vertical output; do that in OBS (the plugin's dock). The plugin is **not included and not installed by IXC** (see below).
- **Automation Studio** is a status page. What works today: chat commands (with per-platform answers, OBS actions, presets), timers, event messages, chat filters, TTS, music. Not built: triggers beyond those, multi-step actions with conditions, variables/counters, run history, import/export of automations.
- **Replies/moderation/alerts** need your own developer apps (see first-run step 2); they were tested with fake platform servers, not with real accounts.
- Not tested on real accounts in this build: YouTube chat while live (a real read test passed earlier today), Twitch/Kick reply sending, `!followage` (one automated test of this preset fails on Windows, cause not found; the command needs a Twitch account anyway).
- The phone remote and quick-connect tests could not run here (they need Cloudflare tooling); they passed in earlier releases.
- Version `3.3.0-rc.1` is not a plain number, so this build's update check will not offer updates. Install the final release by hand.
- The setup program (`.exe`) is built by the project's CI (it needs Inno Setup); the zip + Install.bat are the artifact verified locally.

## Optional: Aitum Vertical Canvas (9:16 output) - manual, not bundled
IXC does not install OBS plugins. If you want a vertical canvas, install the official plugin yourself (GPL-2.0, <https://github.com/Aitum/obs-vertical-canvas>):
1. Download release **1.6.6** asset `vertical-canvas-windows-programdata.zip` from the project's GitHub Releases page; its SHA-256 must be `eba2448e68326f4029531ce3743d83d47f3bd3db50daea140dd41ba0a29d85e7`.
2. Close OBS, unzip into `C:\ProgramData\obs-studio\plugins` (you get `...\plugins\vertical-canvas\bin\64bit\...`), start OBS.
3. Settings in the plugin dock worth checking: turn **Backtrack** off (otherwise the plugin switches OBS's Replay Buffer on at every start) and set a **recording folder**.
4. Known plugin behaviour (seen on OBS 32.2.2): a vertical recording also briefly starts and stops OBS's main recording (a tiny stray file in your recording folder).
Remove it by closing OBS and deleting `C:\ProgramData\obs-studio\plugins\vertical-canvas`. Its licence text is at the project page; IXC ships none of its code.

## Uninstall / roll back
- **Uninstall**: Start menu > *Uninstall IXC* (or `Uninstall.bat`, or Windows Settings > Apps for the setup program). It removes the program, the start-with-Windows entry, the Start-menu entries, IXC's panels in OBS (OBS closed) and IXC's "IXC Audio" scene and sources (OBS open), **and, by default, your IXC settings, sign-ins and stream keys**. To keep them for a reinstall run `powershell -ExecutionPolicy Bypass -File "%LOCALAPPDATA%\IXC-OBS\app\scripts\uninstall.ps1" -KeepSettings`. OBS itself and any plugin you installed are not touched (OBS's WebSocket server stays on).
- **Back to 3.2.0**: run the 3.2.0 setup over it (settings are kept and backed up first in `%LOCALAPPDATA%\IXC-OBS\backups`), or uninstall with `-KeepSettings` and install 3.2.0.
