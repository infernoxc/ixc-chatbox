## ⬇ Install or update

1. Below, under **Assets**, click **`IXC-Suite-v3.3.1.zip`** to download it.
2. Close OBS. Open your **Downloads** folder, right-click the zip > **Extract All…** > **Extract**.
3. In the extracted folder, double-click **`Install.bat`**. No admin rights needed.
   - **"Windows protected your PC"?** Click **More info**, then **Run anyway**. (The checksum is in `SHA256SUMS.txt` below.)

Your settings, accounts, queue and playlists stay (a backup is made first). **Going back:** install v3.3.0 the same way.
New to IXC? Follow the [first-time setup guide](https://github.com/infernoxc/ixc-chatbox/blob/main/docs/FIRST-TIME-SETUP.md).

## What's new in 3.3.1

### 🗣 Natural Indian and Hindi chat voices (Azure AI Speech)
- Chat voice page > **Natural voices (Azure Speech)**: paste the region and key of your own free Azure Speech resource
  (about 500,000 characters a month free). The key is stored encrypted on your PC and is never shown again.
- IXC then offers the Indian English and Hindi voices (male and female) that Azure lists for your region, multilingual voices
  that also speak Hindi, and a soft whisper voice.
- **Speech engine**: Automatic (Azure, with a Windows voice as backup), Azure only, or Windows only. The backup voice always
  speaks the **same language**. For Hindi, install the Windows **Hindi** speech pack (Settings > Time & language > Speech).
- **🎧 Preview here** plays a test sentence in the dashboard only, not on stream.
- **Pronunciation fixes**: `word=how to say it`, one per line.
- If Azure stops answering, IXC pauses it for a minute, uses the Windows voice, then tries Azure again by itself.
- Details and a by-ear checklist: [VOICES.md](https://github.com/infernoxc/ixc-chatbox/blob/main/docs/VOICES.md).

### 🎵 More chat commands (moderators only by default)
- Music: `!shuffle`, `!repeat`, `!volume 40` (or `+10` / `-10`), `!previous`.
- Chat voice: `!ttsvolume`, `!ttsspeed`, `!ttsvoice`, `!ttspause`, `!ttsresume`, `!ttsclear`.
- Add them in **Commands > Ready-made commands** (also `!skip`, `!pause`, `!resume`, `!queue`, `!ttsskip`, `!ttson`, `!ttsoff`).

### 🔧 Fixes
- The **Streams** page is now in the IXC menu.
- Custom voices show up straight away.

**Tested:** automatic tests (Windows and Linux), with a simulated Azure server. **Not yet tested:** real Azure audio and how
natural each voice sounds. Please try **Preview** with a few voices.
