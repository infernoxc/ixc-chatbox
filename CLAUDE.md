# IXC Engineering Instructions

- Preserve existing features and configuration compatibility.
- Inspect targeted files and reproduce bugs before editing.
- Conserve Claude usage: avoid repeated repository-wide scans and long summaries.
- Prefer small, evidence-based fixes over rewrites.
- Run relevant tests after meaningful changes.
- Never claim a test or platform connection succeeded without evidence.
- Protect credentials and redact secrets from logs.
- Never push, merge, publish, or deploy without explicit approval.
- Keep IXC_IMPLEMENTATION_STATUS.md updated with concise, factual progress.
- If blocked, record the exact error and next action.
